# Smart To-Do List

برنامج بايثون بسيط لإدارة المهام من خلال سطر الأوامر.

## المميزات

- إضافة مهمة جديدة.
- عرض جميع المهام.
- حذف مهمة برقمها.
- الخروج من البرنامج.

> هذه النسخة تحفظ المهام مؤقتًا داخل قائمة في بايثون، لذلك تختفي عند إغلاق البرنامج.

## التشغيل

```bash
python3 smart_todo_list.py
```
